# Neo_Café - Fictional Coffee Shop Landing Page

This project is a modern, fully responsive, single-page website for "Neo_Café," a fictional coffee shop with a unique cyber-minimalist and futuristic aesthetic. The design merges clean, brutalist-inspired elements with dynamic animations to create an engaging user experience.

## ✨ Features

- **Futuristic & Minimalist Design:** A unique theme built around a "re-engineered" coffee experience, using a specific color palette and typography (Space Grotesk & Inter).
- **Fully Responsive:** The layout adapts seamlessly to all screen sizes, from large desktops to mobile phones, featuring a functional hamburger menu for mobile navigation.
- **Smooth Animations:**
  - **Scroll Reveal:** Elements gracefully fade and slide into view as the user scrolls down the page.
  - **Interactive Hovers:** Engaging hover effects on gallery items, cards, and buttons.
  - **Blinking Logo:** A subtle blinking animation on the logo to fit the cybernetic theme.
- **Interactive Sections:**
  - **Asymmetrical Image Gallery:** A dynamic, masonry-style grid showcasing images with an interactive overlay on hover.
  - **Expandable Reviews Section:** Displays an initial set of customer reviews with a "See More" button to reveal additional entries.
- **Modern CSS & JS:** Built with modern web standards, including CSS Grid/Flexbox, CSS Variables, and vanilla JavaScript for interactivity without heavy libraries.

## 🛠️ Tech Stack

- **HTML5:** For the core structure and content.
- **CSS3:** For all styling, layout (Flexbox, Grid), animations, and responsiveness.
  - **CSS Variables:** For easy theme management and color consistency.
- **JavaScript (ES6+):** For all client-side interactivity, including:
  - Mobile menu functionality.
  - Scroll reveal animations using `IntersectionObserver`.
  - "See More" button logic.
- **Font Awesome:** For scalable vector icons.
- **Google Fonts:** For custom web fonts.
